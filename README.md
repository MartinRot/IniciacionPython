## 📌 Pre-entrega: Gestor de Productos con Menú Interactivo

Desarrollo de un programa interactivo en consola para administrar una lista de productos utilizando conceptos fundamentales de Python:
- Listas y métodos (`.append()`, `.remove()`)
- Bucle `while` y control de flujo
- Condicionales `if`, `elif`, `else`
- Bucle `for` para iteraciones
- Validaciones de entrada de usuario
